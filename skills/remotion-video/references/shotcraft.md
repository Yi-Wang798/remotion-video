# Shotcraft references

```text
node <plugin>/scripts/setup.mjs --with shotcraft
```

This downloads a pinned selection into `vendor/video-shotcraft`: data shot cards and demos, depth-layer camera motion, type assembly, title-to-label, line-carry transitions, timing guidance, shared demo fixtures and attribution. Select by the job the shot must do, then read the card and corresponding actual `.tsx` demo together. Start from its tested timing and layout rather than only borrowing an effect name.

- Data: use a scale, pointer, timeline or comparison when it explains the quantity.
- Typography: reveal a phrase, then preserve its useful word as a label to connect shots.
- Camera: separate layers only when depth explains the structure; maintain caption clearance.
- Transition: carry a line or another stable element across a cut to connect states.
- Rhythm: balance motion with readable holds; use the visual event or narration to place the accent.

Keep relevant fixtures and imported helpers when adapting a demo. Demos with product-specific assets need replacement assets from the current project. Inspect dependencies before using one. Record the source card/demo in project notes, and retain applicable notices with copied code. Remotion Bits remains the first component/example lookup; Shotcraft adds shot composition and timing references.

Use the unified project's plan, review records and delivery flow. Apply Shotcraft's detailed shot methods where useful; user-delegated creative choices remain delegated. Audio libraries are outside this guide selection; choose audio with its own source and license record when audio is requested.

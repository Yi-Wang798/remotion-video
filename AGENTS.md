# Maintaining this plugin

Update README files when behavior, setup or examples need explaining; a release does not require a README edit. Whenever changing `README.md` or `README.en.md`, apply the available Humanizer skill to the changed prose (Humanizer ZH for Chinese). Preserve commands, facts, links and attribution. Keep the review draft outside the repository and publish only the finished prose.

Keep route resolution, validation and documentation consistent. Test changes to export gates with both an illustrated plan and simple direct work. Preserve legacy-plan behavior unless a migration is explicitly intended. Never record unperformed image generation, playback, listening or visual review as passed.

# Painted river study

An original eight-second fish encounter using Huashu's actual `PAINT.strokes` and `PAINT.swatch` implementation. No generated images are required. Create a project with `styles.mjs create --style huashu/09_postimp`, then replace `src/native/scenes/project_scene.js` with this `scene.js` and render eight seconds. The design stage is 1920×1080; output can be 960×540 or 1920×1080.

This is a drawing/motion integration sample, not a narrated finished video. The scene is original MIT code. The copied renderer remains copyright alchaincyf and retains its upstream MIT, font and data notices. See the root NOTICE.md for pinned provenance.

# Changes

## 3.1.0

- Added a shared creative-design stage for every video type, with independent expression profiles and production paths.
- Added compact layout previews and timed animatics before detailed production, plus an engagement pass on the finished film.
- Added version 3 creative/shot metadata, separate design review hashes, pending evidence and export checks.
- Added advisory composition/reveal repetition reports, with no required location count or cut interval.
- Updated connected-image guidance to preserve identity while varying viewpoint, scale, staging and light.
- Reconciled workflow, preview, review, writing and vendor-guide instructions; updated both READMEs and a data example.
- Preserved version 1/2 plan behavior and added cross-profile regression tests.

## 3.0.0

- Added direct and designed production paths, with automatic selection and manual overrides.
- Added light and segment review levels, shot dependency hashes and adjacent-cut invalidation.
- Added an export command that checks current review records before final rendering, and fixed project-relative public asset loading in review renders.
- Added data source, unit/currency and derived-metric checks.
- Added an isolated optional Manim CE runtime, rendering wrapper and hybrid example.
- Added pinned optional Manim guides and a selected Shotcraft card/demo pack.
- Added shared visual-system guidance and adapters for local frontend design skills.
- Rewrote Chinese and English READMEs with concise usage, examples and credits.
- Preserved version 1 plan compatibility and expanded regression tests.
